## Design pass, first

For each section: does it belong? Is it told in the best order? Would a different story teach better? If so, propose the better flow outright, as a judgment and not only as a list of defects.

## Use test

Take [a variant the text does not treat], and carry out the procedure on it from the text alone.
Report where you got stuck. That is usually the most useful finding.

## Correctness pass, second

Report any statement that is false, inexact or missing a hypothesis. Name each object or symbol used before it is defined. List vague phrases that point at something instead of naming it.

## Form of the report

Numbered items, each with an exact location and the smallest replacement on the argument's main line.
Say which items are high, medium and low. Skip asides about exact behavior or plot appearance unless the reader needs them.
A proposed cut is a proposal to flag and keep. Never edit the document.
