# Brief template: inventory of existing work

Use one inventory per part, before planning that part. Fill in the brackets.

Report what actually exists for [part] in [folders]. Do not plan yet, and do not edit anything.

For every result, code path or claim you find, tag it with one label:

- TESTED: code with tests, or a result you reran and reproduced. Give the command and the number.
- IMPLEMENTED: code that runs but has no tests.
- DESCRIBED: stated in a document, with no code or data behind it.
- CLAIMED: a number or statement with no recoverable source.

Say what is real data and what is synthetic.
List what is missing for the stated goal, the real bottlenecks, and any discrepancy between a document and its source.
Add a short proposal for the smallest running example or next demonstration, with what it would test.
Keep citations to file and line. Write the report to [path].
